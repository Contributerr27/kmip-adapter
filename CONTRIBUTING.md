# Contributing

Thanks for helping! Start with the [contributing guide](docs/guides/contributing.md) (workflow,
commit style, code style) and [First contribution](docs/guides/first-contribution.md).

Quick start:

```bash
git clone https://github.com/appmonster007/kmip-adapter.git
cd kmip-adapter
git checkout -b feature/<short-name> develop
mvn test        # must pass, checkstyle included (Java 21)
```

- Pick an issue labeled [`good first issue`](https://github.com/appmonster007/kmip-adapter/labels/good%20first%20issue)
  or [`help wanted`](https://github.com/appmonster007/kmip-adapter/labels/help%20wanted), and comment
  that you're taking it.
- Open PRs against `develop`. Use Conventional Commits.
- Say so in the PR if you used AI.
- Questions: use [Discussions](https://github.com/appmonster007/kmip-adapter/discussions).

By contributing you agree your work is licensed under LGPL v3.
